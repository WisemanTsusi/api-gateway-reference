# Cloud Mapping

| Capability | AWS | Azure | GCP |
|---|---|---|---|
| CDN/edge | CloudFront | Front Door | Cloud CDN |
| WAF | AWS WAF | Azure WAF | Cloud Armor |
| API gateway | API Gateway | API Management | API Gateway |
| Containers | ECS/EKS | Container Apps/AKS | Cloud Run/GKE |
| Secrets | Secrets Manager | Key Vault | Secret Manager |
| Observability | CloudWatch/X-Ray | Azure Monitor | Cloud Monitoring/Trace |

The implementation remains provider-neutral; native managed services can provide the production edge.
